# Carrying capacity as a bound variable

An interactive figure. In population ecology, carrying capacity is the
coefficient K of the logistic growth equation, defined only relative to a
species, an environment, a resource-renewal regime and a timescale. K is
therefore a function of four arguments, and returns a number only once all
four are bound. In collapsological usage the argument-places are silently
deleted and the result is spoken of as a single fixed quantity.

This figure makes that deletion operable: bind the arguments and the number
moves across more than an order of magnitude; leave one free and there is no
number at all.

**Live version:** https://edithlaszny.github.io/carrying-capacity/

A single self-contained HTML file. Bilingual (English, Hungarian). Runs in any
modern browser, offline, with no installation and no data collected.
No build step, no dependencies.

## Note on the figures

The figures are illustrative, not measured. The model is a schematic product of
four factors of no independent provenance, chosen so that the published
estimates of two, ten and forty billion fall inside its range. No value shown
is an estimate of any quantity, and none should be cited as one.
